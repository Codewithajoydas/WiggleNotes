# WiggleNote

An offline-first desktop notebook for writing, organizing, and managing knowledge.

[![Download](https://img.shields.io/badge/Download-Windows-blue?style=for-the-badge)](https://github.com/Codewithajoydas/WiggleNotes/releases/latest)

## Download

**Latest Release**

https://github.com/Codewithajoydas/WiggleNotes/releases/latest

---

## Features

* Offline-first
* Rich Text & Markdown Editor
* Fast and responsive
* Local SQLite storage
* Powerful search
* Reusable templates
* Keyboard shortcuts
* Cross-platform desktop application
* Automatic updates

## Development

```bash
git clone https://github.com/Codewithajoydas/WiggleNotes.git

cd WiggleNotes

npm install

npm run dev
```
